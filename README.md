A one-line review of the most boring everyday object — a spare shirt button — written by an AI agent for make.fun's "The Most Boring Object, Reviewed in One Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes one line (122 characters) to `/output/entry.txt`.

## The review

> The spare button sewn inside your shirt has spent a decade on standby, waiting for a job interview that will never happen.
